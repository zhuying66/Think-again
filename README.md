# 再考虑考虑 (Think Again)

拿不准一件事该不该做时,进来回答几道题,让它帮你把做与不做的利弊理出个倾向。

> 开源协议:[MIT](LICENSE) · © 2026 zhuying66

> 本结果仅供参考,不构成任何专业建议,最终决定权在于你自己。

## 它是做什么的

面对「拿不准」的事,先确定问题的**分量**,再按直觉作答:

**① 自动判断问题规模**(推荐)

回答 5 道规模判断题,量化这件事的**影响范围、持续时间、不可逆性、代价、对他人的影响**,
本地求和后自动归入小问题或大问题:

```
totalScore = Q1 + Q2 + Q3 + Q4 + Q5      // 每题 1~5 分,范围 5 ~ 25
5  ~ 14 分 → 小问题
15 ~ 25 分 → 大问题
```

判定完全离线(纯本地代码),不接入任何 AI / API / 网络;结果只给一句提示,不展示分数。
若觉得判断不符合实际情况,可在结果页点「**我想自己选择**」手动指定规模。

**② 或者自己选择分量**

- **小问题** — 日常琐事,6 道题快速判断
- **大问题** — 重要决定,16 道题详细分析

答完后根据你的回答综合给出三档结论:

| 结论 | 含义 |
| --- | --- |
| 推荐去做 | 潜在收益和意义大于成本与风险 |
| 建议谨慎考虑 | 有价值,但仍需进一步权衡 |
| 不太推荐去做 | 潜在成本或风险可能超过收益 |

### 特殊规则(大问题)

- **高风险压制**:第 10 题存在可能造成严重负面后果的风险答「是」→ 最高只能给「建议谨慎考虑」
- **条件不足**:第 11 题(承担能力)与第 13 题(基本条件)同时答「不是」→ 直接判定「不太推荐去做」

## 功能一览

-   **自动判断问题规模**:5 道标准题本地评分,自动选择更适合的分析方式(可手动改)
-  小 / 大两套独立题库,「是 / 不是」作答,答题页可返回上一题修改
-  每题设「是/不是」不同权重,结果按加权分 + 特殊规则动态生成,**不用固定文案**
-  浅色 / 深色 / 跟随系统 三种外观
-  答题详情:结果页与记录页都可回看每题题目与你的选择
-  历史记录本地保存(Room),支持查看详情 / 删除全部
-  **记录页左滑操作**:左滑可「编辑名称」(自动拉起输入法)或「删除该条记录」
-  设置页可清理 App 缓存、删除所有记录,并提供 GitHub 仓库直达入口

## 技术栈

- **Kotlin + Jetpack Compose + Material 3**
- Navigation Compose / ViewModel / Room / DataStore
- 本地规则算法(题库、权重、评分独立管理,便于日后替换为 AI 判断引擎)

## 构建

```bash
# 环境:JDK 17、Android SDK(compileSdk 35)、minSdk 26
./gradlew assembleRelease
# 产物:app/build/outputs/apk/release/app-release.apk
```

> Release 使用 debug.keystore 签名(个人分发用途)。
